# 🔬 LabMate AI

**An AI-powered Engineering Laboratory Preparation Assistant**

LabMate AI is a web-based application designed to help engineering students prepare for laboratory experiments more effectively. It aims to simplify experiment concepts, provide structured lab guides, and help students prepare for practical examinations and viva questions.

## 🎯 Project Objectives

- Make engineering laboratory preparation easier.
- Explain complex experiment concepts in simple language.
- Provide organized experiment guides.
- Help students prepare for laboratory viva examinations.
- Make practical learning more interactive.

## ✨ Current Features

- Modern and responsive user interface.
- Subject-wise experiment categories.
- Experiment search functionality.
- Popular experiment listings.
- Recent experiment history.
- Python FastAPI backend.
- API endpoint for receiving experiment requests.
